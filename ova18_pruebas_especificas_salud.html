Contexto Clínico de las Pruebas de Hipótesis

Las pruebas de hipótesis son fundamentales en la investigación médica para:

Ensayos Clínicos

Evaluar la eficacia de nuevos tratamientos comparados con placebo o tratamiento estándar.

Estudios Epidemiológicos

Determinar asociaciones entre factores de riesgo y enfermedades en poblaciones.

Diagnóstico Clínico

Comparar valores de laboratorio con rangos de referencia normales.

Importancia en la Práctica Médica

Medicina Basada en Evidencia

Las pruebas estadísticas proporcionan el rigor científico necesario para validar intervenciones médicas y establecer guías de práctica clínica.

Control de Errores

La corrección por comparaciones múltiples evita conclusiones erróneas cuando se realizan múltiples pruebas simultáneas.

Pruebas Z y T para Medias

Prueba Z (Z-test)

Cuándo usar: Cuando σ (desviación estándar poblacional) es conocida y n ≥ 30

Fórmula:

$$Z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}}$$

Ejemplo clínico: Comparar la presión arterial promedio de un grupo de pacientes con el valor poblacional conocido.

Prueba T (T-test)

Cuándo usar: Cuando σ es desconocida o n < 30

Fórmula:

$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}$$

Ejemplo clínico: Evaluar si un nuevo medicamento reduce significativamente los niveles de colesterol.

Tipos de Pruebas T

Una muestra

Comparar la media de una muestra con un valor conocido

Ej: ¿La glucosa promedio difiere de 100 mg/dL?

Dos muestras independientes

Comparar medias de dos grupos independientes

Ej: Comparar presión arterial entre hombres y mujeres

Muestras pareadas

Comparar medidas antes y después en los mismos sujetos

Ej: Peso antes y después de un tratamiento

Supuestos de las Pruebas

  • • Normalidad: Los datos deben seguir una distribución normal
  • • Independencia: Las observaciones deben ser independientes
  • • Homocedasticidad: (Para dos muestras) Varianzas iguales entre grupos
  • • Nivel de medición: Variable dependiente debe ser continua

Ejemplo Práctico: Eficacia de un Antihipertensivo

Contexto del Estudio

Un nuevo medicamento antihipertensivo se prueba en 25 pacientes. Se mide la presión arterial sistólica antes y después del tratamiento.

Datos del Estudio

  • • n: 25 pacientes
  • • Media antes: 145 mmHg
  • • Media después: 138 mmHg
  • • Desviación estándar de diferencias: 8.5 mmHg
  • • α: 0.05

Solución Paso a Paso

1. Hipótesis:
H₀: μd = 0 (no hay diferencia)
H₁: μd ≠ 0 (hay diferencia)
2. Estadístico de prueba:
t = (7 - 0) / (8.5/√25) = 4.12
3. Valor crítico:
t₀.₀₂₅,₂₄ = ±2.064
4. Conclusión:
Como |4.12| > 2.064, rechazamos H₀.
El medicamento es efectivo (p < 0.001).

Pruebas de Hipótesis para Proporciones

Una Proporción

Cuándo usar: Comparar una proporción observada con un valor esperado

Fórmula:

$$Z = \frac{\hat{p} - p_0}{\sqrt{\frac{p_0(1-p_0)}{n}}}$$

Ejemplo: ¿La tasa de curación de un tratamiento es mayor al 80%?

Dos Proporciones

Cuándo usar: Comparar proporciones entre dos grupos independientes

Fórmula:

$$Z = \frac{\hat{p_1} - \hat{p_2}}{\sqrt{\hat{p}(1-\hat{p})(\frac{1}{n_1} + \frac{1}{n_2})}}$$

Ejemplo: Comparar tasas de infección entre dos hospitales

Aplicaciones Clínicas Comunes

Estudios de Eficacia

  • • Tasa de respuesta a tratamientos
  • • Proporción de pacientes curados
  • • Efectividad de vacunas
  • • Tasas de supervivencia

Estudios Epidemiológicos

  • • Prevalencia de enfermedades
  • • Incidencia de eventos adversos
  • • Factores de riesgo
  • • Comparación entre poblaciones

Condiciones de Aplicación

Supuestos Necesarios:

  • • Muestreo aleatorio
  • • Observaciones independientes
  • • np ≥ 5 y n(1-p) ≥ 5
  • • Población grande (n < 10% de N)

Alternativas si no se cumplen:

  • • Prueba exacta de Fisher
  • • Corrección de continuidad
  • • Métodos no paramétricos
  • • Intervalos de confianza exactos

Caso Práctico: Comparación de Tratamientos

Estudio Clínico

Se compara la efectividad de dos antibióticos para tratar infecciones respiratorias. Se quiere determinar si hay diferencia significativa en las tasas de curación.

Datos del Estudio

Tratamiento Curados Total Proporción
Antibiótico A 85 100 0.85
Antibiótico B 78 100 0.78

Análisis Estadístico

1. Hipótesis:
H₀: p₁ = p₂ (no hay diferencia)
H₁: p₁ ≠ p₂ (hay diferencia)
2. Proporción combinada:
p̂ = (85+78)/(100+100) = 0.815
3. Estadístico Z:
Z = (0.85-0.78)/√[0.815×0.185×(1/100+1/100)]
Z = 1.27
4. Conclusión:
Como |1.27| < 1.96, no rechazamos H₀.
No hay diferencia significativa (p = 0.204).

Comparaciones Múltiples y Corrección de Bonferroni

El Problema de las Comparaciones Múltiples

Cuando realizamos múltiples pruebas de hipótesis simultáneamente, la probabilidad de cometer al menos un Error Tipo I (falso positivo) aumenta dramáticamente.

Probabilidad de Error Tipo I familiar:

$$\alpha_{familiar} = 1 - (1-\alpha)^k$$

Donde k = número de comparaciones

Corrección de Bonferroni

Método: Dividir α por el número de comparaciones

$$\alpha_{ajustado} = \frac{\alpha}{k}$$

Ventaja: Método simple y conservador

Desventaja: Puede ser demasiado conservador

Otros Métodos de Corrección

  • Holm-Bonferroni: Menos conservador que Bonferroni
  • Benjamini-Hochberg: Control de tasa de falso descubrimiento
  • Tukey HSD: Para comparaciones post-hoc en ANOVA
  • Dunnett: Para comparar múltiples grupos con control

La elección del método depende del contexto y objetivos del estudio

Ejemplo: Inflación del Error Tipo I

Número de Comparaciones α individual (0.05) α familiar (sin corrección) α Bonferroni
1 0.050 0.050 0.050
3 0.050 0.143 0.017
5 0.050 0.226 0.010
10 0.050 0.401 0.005

Caso Práctico: Estudio de Múltiples Biomarcadores

Estudio de Biomarcadores

Un estudio evalúa 6 biomarcadores diferentes para predecir riesgo cardiovascular. Se comparan los niveles entre pacientes con y sin eventos cardiovasculares.

Resultados de las Pruebas

Biomarcador Valor p Significativo (α=0.05)
CRP 0.012 Sí
IL-6 0.034 Sí
TNF-α 0.089 No
BNP 0.003 Sí
Troponina 0.156 No
D-dímero 0.047 Sí

Aplicando Corrección de Bonferroni

α ajustado:
α = 0.05 / 6 = 0.0083
Resultados corregidos:
• CRP: p=0.012 > 0.0083 → No significativo
• IL-6: p=0.034 > 0.0083 → No significativo
• BNP: p=0.003 < 0.0083 → Significativo
• D-dímero: p=0.047 > 0.0083 → No significativo
Conclusión:
Solo BNP mantiene significancia estadística después de la corrección por comparaciones múltiples.

Interpretación Clínica

La corrección de Bonferroni ayuda a identificar los biomarcadores con evidencia más sólida, reduciendo la probabilidad de falsos positivos en estudios exploratorios.

Caso 1: Eficacia de un Nuevo Antidiabético

Contexto del Estudio

Un laboratorio farmacéutico desarrolló un nuevo medicamento para diabetes tipo 2. Se realizó un ensayo clínico randomizado controlado para evaluar su eficacia comparado con el tratamiento estándar.

Datos del Estudio

  • • Diseño: Ensayo clínico aleatorizado
  • • Participantes: 200 pacientes con diabetes tipo 2
  • • Grupos: Nuevo medicamento (n=100) vs Estándar (n=100)
  • • Variable principal: Reducción de HbA1c a 6 meses
  • • Objetivo: Demostrar superioridad (diferencia ≥ 0.5%)

Resultados

Nuevo Medicamento:
Media: -1.8% HbA1c
DE: 0.9%
n: 100
Tratamiento Estándar:
Media: -1.2% HbA1c
DE: 0.8%
n: 100

Pregunta de Análisis:

¿Es el nuevo medicamento significativamente superior al tratamiento estándar?

Solución Paso a Paso

1. Planteamiento de Hipótesis:
H₀: μ₁ - μ₂ ≤ 0.5 (no superioridad)
H₁: μ₁ - μ₂ > 0.5 (superioridad)
2. Selección de Prueba:
Prueba t para dos muestras independientes
(muestras grandes, varianzas similares)
3. Cálculos:
Diferencia observada: 1.8 - 1.2 = 0.6%
Error estándar: √[(0.9²/100) + (0.8²/100)] = 0.12
t = (0.6 - 0.5) / 0.12 = 0.83
4. Conclusión:
t = 0.83 < t₀.₀₅,₁₉₈ = 1.65
No se demuestra superioridad (p = 0.204)

Caso 2: Factores de Riesgo Cardiovascular

Contexto del Estudio

Un estudio de cohorte prospectivo evaluó múltiples factores de riesgo para enfermedad cardiovascular en una población de 5000 adultos seguidos durante 10 años.

Factores Evaluados

  • • Hipertensión arterial
  • • Diabetes mellitus
  • • Tabaquismo
  • • Obesidad (IMC ≥ 30)
  • • Dislipidemia
  • • Sedentarismo

Resultados (Valores p)

Factor de Riesgo Valor p
Hipertensión 0.001
Diabetes 0.003
Tabaquismo 0.012
Obesidad 0.045
Dislipidemia 0.089
Sedentarismo 0.156

Análisis con Corrección de Bonferroni

α ajustado:
α = 0.05 / 6 = 0.0083
Factores significativos:
• Hipertensión: p = 0.001 < 0.0083 ✓
• Diabetes: p = 0.003 < 0.0083 ✓
• Otros: p > 0.0083 ✗
Interpretación Clínica:
Después de ajustar por comparaciones múltiples, solo la hipertensión y diabetes mantienen asociación significativa con enfermedad cardiovascular.

Caso 3: Valores de Referencia de Laboratorio

Contexto del Estudio

Un laboratorio clínico quiere validar si los niveles de creatinina en una población local difieren significativamente de los valores de referencia internacionales (1.0 mg/dL para hombres).

Datos de la Muestra

  • • n: 150 hombres adultos sanos
  • • Media: 1.08 mg/dL
  • • Desviación estándar: 0.25 mg/dL
  • • Valor de referencia: 1.0 mg/dL
  • • Nivel de significancia: α = 0.05

Pregunta de Investigación

¿Los niveles de creatinina en la población local difieren significativamente del valor de referencia internacional?

Análisis Estadístico

Prueba apropiada: t-test para una muestra
(n > 30, σ desconocida)
Estadístico t:
t = (1.08 - 1.0) / (0.25/√150) = 3.92
Valor crítico: t₀.₀₂₅,₁₄₉ = ±1.976
Conclusión:
Como |3.92| > 1.976, rechazamos H₀.
Los niveles locales difieren significativamente (p < 0.001).
